# Nata Flowers, сайт-визитка

Одностраничный сайт для Натальи. Она выращивает цветы на своём участке в Гомеле,
срезает их при покупателе и собирает букеты на заказ. Самовывоз, Западный район.

**Стек:** HTML + Tailwind (CDN) + GSAP. Сборка не нужна: сайт открывается двойным
кликом по `index.html` и так же выкладывается на любой хостинг.

## Что нужно доделать

Три вещи, без которых сайт неполный:

1. **Контакты.** Файл `js/main.js`, объект `CONTACTS` в самом верху. Сейчас заполнен
   только Instagram. Добавьте Telegram, телефон и остальное. Пустые поля просто
   не отрисуются, ломаться нечему.
2. **Фотографии.** Смотрите `images/README.md`. Пока файлов нет, на их местах стоят
   заглушки с подписями.
3. **Отзывы.** Файл `index.html`, секция `#reviews`. Там сейчас три пунктирные
   карточки-заглушки. Перенесите настоящие отзывы из актуального «Отзывы» в Instagram.
   Выдуманные отзывы публиковать не стоит: это вводит покупателей в заблуждение,
   поэтому там оставлены заглушки, а не придуманный текст.

## Структура

```
index.html                    вся разметка
css/styles.css                стили поверх Tailwind
js/main.js                    контакты и анимации
images/                       фото, внутри свой README
design-system/nata-flowers/   MASTER.md с токенами и правилами
```

## Дизайн-система

| | |
|---|---|
| Заголовки | Cormorant Garamond |
| Основной текст | Manrope |
| Каллиграфия | Great Vibes: названия цветов, подписи, акценты |
| Основной цвет | `#2E5E3A`, зелёный «сад» |
| Акцент | `#B92F58`, цвет её пионов, все главные кнопки |
| Фон | `#FDFAF6`, тёплый кремовый |
| Анимации | GSAP и ScrollTrigger, 300 до 450 мс |

### Про шрифты и кириллицу

Это главная ловушка проекта. Большинство красивых каллиграфических шрифтов Google Fonts
кириллицу **не поддерживают**, и русский текст в них молча заменяется системным шрифтом.
Проверено запросом к Google Fonts API:

- **Без кириллицы:** Dancing Script, Parisienne, Pinyon Script, Italianno, Tangerine,
  Alex Brush, Sacramento, Rouge Script, Playball.
- **С кириллицей:** Great Vibes, Marck Script, Bad Script, Pacifico, Lobster, Neucha,
  Yeseva One, Kurale, Cormorant Infant.

Выбран Great Vibes: у него диапазон `U+0400-045F`, то есть весь русский алфавит,
и при этом он единственный из кириллических даёт настоящий копперплейт, а не бытовой
рукописный почерк.

Если будете менять шрифт, сначала проверьте кириллицу:

```bash
curl -s "https://fonts.googleapis.com/css2?family=ИМЯ+ШРИФТА&display=swap" | grep cyrillic
```

Пусто в ответе означает, что кириллицы нет и шрифт не подойдёт.

### Отступления от сгенерированной дизайн-системы

Генератор предложил пару Amatic SC и Cabin. **Ни в одном из них нет кириллицы**,
русский текст не отобразился бы вообще. Также предлагался мятный фон `#F0FDF4`,
который конфликтует с малиновыми пионами на фото, поэтому фон заменён на тёплый
кремовый. Зелёный остался цветом сада, малиновый работает акцентом.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Если нужен http:

```bash
python -m http.server 5173
```

## Публикация

Любой статический хостинг: Netlify перетаскиванием папки, GitHub Pages, Vercel,
обычный хостинг по FTP. Собирать ничего не нужно.

Одно замечание. Tailwind подключён через CDN и компилирует стили прямо в браузере.
Для визитки это нормально, но если захотите ускорить загрузку, стили можно собрать
заранее и подключить готовый CSS-файл.

## Доступность и адаптив

- Контраст текста от 4.5:1, проверенные значения от 5.8 до 11.3
- Видимые focus-состояния, все кнопки от 44px
- Работает без JS: анимации не запускаются, весь контент виден
- `prefers-reduced-motion` отключает анимации и лепестки
- Проверено на 375, 768, 1024, 1440
