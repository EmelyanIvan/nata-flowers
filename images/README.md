# Фотографии

Положите файлы в эту папку **с точно такими именами**, они подставятся сами.
Пока файла нет, на его месте показывается аккуратная заглушка с подписью,
вёрстка при этом не ломается.

## Как готовить фото

- **Берите оригиналы с телефона, а не скачанные из Instagram.** Instagram пережимает
  примерно до 640px по ширине, для главного экрана этого мало и будет мыло.
- Перед загрузкой сожмите на [squoosh.app](https://squoosh.app), качество 75 до 80%.
  Цель уложиться в 400 КБ на файл, для главного фото допустимо до 600 КБ.
- Кадрируйте под пропорции из таблицы. Если пропорции не совпадут, фото обрежется
  по центру (`object-fit: cover`), и важное может уйти за край.
- Для `og.jpg` возьмите самый выигрышный горизонтальный кадр. Именно он появится
  в превью, когда ссылку кинут в Telegram, Viber или WhatsApp.

## Если фото называется иначе

Можно не переименовывать, а поправить путь в `index.html`. Найдите нужный
`<img src="images/...">` и укажите своё имя файла.
